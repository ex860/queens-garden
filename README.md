# 皇后花園

8×8 邏輯遊戲，256 關，支援多解、輔助標記及勝利動畫。

純 HTML、CSS、JavaScript，無須建置。點擊順序為 X → 皇后 → 清空，拖曳可連續標記 X。

「上一步」可撤銷最近 200 次操作，每次點擊或整段拖曳算一步。撤銷會同步重算輔助標記；完成後也能撤銷最後一步重新操作。歷史隨進度存入瀏覽器，重新整理後仍可使用；重新開始或換題會清空該局歷史。

## 關卡品質

256 關允許多解，但必須有可推理的切入點。每關開局至少能排除 6 格、至少推進 3 輪，且不用猜測就能確定至少 2 位皇后。每色至少 2 格、至多 18 格，色塊保持連通，至少 5 色的輪廓不是完整矩形。

篩選器使用色塊候選格之間的互斥關係、行列與色塊的鎖定關係，不讀取預存答案。多解題不保證能單靠排除確定全部八位皇后；任何合法配置仍算過關。

使用 Node.js 執行 `node tools/level-quality.cjs` 可重新產生固定種子的題庫；執行 `node tools/verify-quality.cjs` 可檢查品質門檻，並列舉所有合法解，驗證推理沒有錯誤刪除候選格。

更新題庫時保留正在遊玩的棋盤與標記，下一關開始使用新題庫。

## GitHub Pages

將本資料夾中的檔案上傳到儲存庫根目錄，保留 `.nojekyll`。
到 Settings → Pages，選擇 Deploy from a branch、main、/(root)，儲存後等待部署完成。

遊戲進度存在瀏覽器的 localStorage。不同網站網址的儲存空間互相獨立，因此原 Sites 網址的進度不會自動轉移到 GitHub Pages。
